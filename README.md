# Ejercicio-Quimica 
Explicación del código

- Se define una matriz bidimensional llamada configuracionElectronica que almacena los orbitales.
- Se usa un bucle for anidado para recorrer filas y columnas.
- Se omiten los espacios vacíos ('') para mostrar solo los orbitales existentes.
- El resultado se imprime en la consola del navegador usando console.log().

Tecnologías utilizadas

- HTML5
- JavaScript
